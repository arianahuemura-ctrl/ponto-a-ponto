# Compact stop catalogue v1
GET /api/sptrans/stop-catalogue/ returns JSON {version:1, revision:string, scale:100000, rows:[[id:string, deltaLat:int, deltaLon:int, name:string],...]}. Coordinates accumulate from zero, divided by scale. Rows are spatially sorted. Precision is 0.00001 degrees. Names preserve immediate marker labels; line directions/details remain available through /api/sptrans/stops/.
Content-Encoding: gzip when accepted (including quality negotiation); Vary: Accept-Encoding. ETag identifies database revision and schema. If-None-Match returns 304. Cache-Control: private, no-cache permits storage but requires validation. Catalogue contains static GTFS stops only, never live bus positions. Browser retains one version in IndexedDB, validates on startup, and falls back to viewport queries on failure. No reduction in point density.
